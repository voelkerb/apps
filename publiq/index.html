Features

  • MQTT 5Connect to any broker, with optional TLS and user name and password.
  • Live messagesSubscribe with wildcards and watch traffic as it arrives.
  • JSON treeBrowse payloads as an expandable tree.
  • PlotsChart numeric values over time with pinch zoom, pan and full screen.
  • PublishQoS 0, 1 or 2, optionally retained, and delete retained messages.
  • ExportSave the log as text or CSV.
